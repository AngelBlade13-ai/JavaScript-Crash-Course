# JavaScript Crash Course

A beginner DOM project from a JavaScript crash course. The page has a simple user form for entering a name and email, validates that both fields are filled in, and appends submitted users to a list.

## Features

- Name and email inputs
- Submit handler with `preventDefault`
- Empty-field validation message
- Dynamic list item creation
- Form clearing after successful submit

## How To Run

Open `index.html` in a browser.

## Files

```text
index.html
styles.css
main.js
```

## What I Practiced

- Selecting DOM elements
- Form submit events
- Preventing default browser behavior
- Creating list items with JavaScript
- Showing and clearing validation messages
